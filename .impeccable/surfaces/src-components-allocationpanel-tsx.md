# 月度费用分摊

模式：Operate。计划与分摊中的费用分摊标签，面向在电脑和手机核对月度费用的个人或家庭成员。

本页先解释“日常费用（扣除退款） + 本月分摊费用 = 本月费用合计”，再直接展示分页的分摊明细。原付款从日常费用中排除，费用分摊不产生新付款，也不改变钱包余额。每项显示原付款、退款（如有）、覆盖时间、周期、本月金额及覆盖状态；有写权限时可展开调整设置。费用列表本身不得折叠。

延续应用奶油白、暖墨和青绿系统。桌面采用横向金额等式与可扫读明细；手机合计独占一行，明细字段换行，调整按钮整行。保留加载、错误重试、空状态、只读权限和分页。

数据仍使用 allocations API；指定日期范围时发送 startDate/endDate（结束日含当天），服务端转换为现有按天分摊记录，不增加数据库字段。本页展示当前账本已有分摊，包含未开始和已结束项目，状态由选中月份决定。
