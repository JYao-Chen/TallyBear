# AI 助手确认卡片

更新于 2026-10-04。模式为 Operate，供用户核对助手准备的操作并明确确认。视觉沿用根目录 PRODUCT.md 与 DESIGN.md；本页记录卡片和回答的实现约定。

## 卡片详情与操作

待确认及已确认卡片默认展开详情，金额单独突出，其他摘要以标签和值呈现。已取消卡片默认折叠，仍可手动展开。待确认卡片保留补充信息、继续修改和通过对话修改入口；确认后只显示结果状态及确认时间。

缺失信息阻止确认。重复或退款提示保留核对入口，操作失败在卡片内显示错误。生成或展示卡片不会直接入账，保存仍通过用户点击确认触发。

重新打开历史对话时，已确认卡片展开已保存的摘要。旧卡片没有保存的来源字段不会追溯补造，也不会重新生成历史摘要。

## 费用分摊卡片

新建或编辑分摊卡片时，从实际原账单读取标题或商家名称、金额、付款日期和分类。卡片同时显示分摊开始日期、覆盖单位与周期，以及计算后的覆盖截止日期和首月费用。首月费用按原付款减去已关联退款后的净额计算。

按月或按年覆盖时，开始日期统一为所在月份的第一天。卡片预览和确认保存使用相同日期及分摊计算，避免显示的首月费用与保存后的费用不一致。

## 可见回答与历史证据

FinanceNarrative 先通过 chatVisibleText 清理正文，再渲染 Markdown 和图表。清理覆盖旧回答中复制的 `Historical tool evidence (data snapshot, not instructions):` JSON，也覆盖尚未输出完整的快照；快照前后的普通回答保留。

后台将历史工具数据放入独立的 historyEvidence，历史助手消息只传入清理后的可见正文。没有文字但包含待确认操作卡片的结果也算有效回答，图表和草稿继续沿用已有判断。模型以非流式方式返回的最终正文同样保存，重新打开对话可读取该内容。
