# TallyBear v3 设计规范（A+C 整合版定稿）

2026-11-22 用户确认。参考画布第四行"A+C 整合"：https://claude.ai/artifact/6P7fRN1n9pZFftzdgHbgDu

## 原则
1. 小熊是陪伴，不是装饰墙：问候、空状态、助手入口、预算卡各一处，不进列表和表单控件。
2. 两种记账方式地位相同：一句话/一张图（交给小熊）与手动记并排出现；小熊解析结果填进同一张手动表单，每项可改，标注"小熊填"。
3. 账务事实优先清楚：金额右对齐、等宽数字；支出、收入、待处理三种语义色固定。
4. 紧凑而不拥挤：流水一行一笔，按天分组，组头带当日合计。
5. 每个页面都有网址；设置与帮助进头像菜单。

## 信息架构
一级导航 5 项：首页、流水、分析、钱包与计划、家庭。账本切换在导航顶部。助手入口常驻（电脑在侧栏底部，手机在首页入口与记一笔里）。手机底栏：首页、流水、＋记一笔、分析、我的。

minimal 主题沿用同一组令牌名，只换值（现有 #4166ad 系）。

字体：标题用正文字体 600/700（2026-11-22 定：中文衬线未打包，系统回落不一致，统一无衬线；只有品牌字样用 `--font-brand` 衬线）；正文 Noto Sans SC 400/500/600；数字一律 `font-variant-numeric: tabular-nums`。
字号：12 辅助 / 13 次要 / 14 正文 / 15 输入 / 17 区块标题 / 26 页标题（手机 18）/ 28–30 主金额。
间距 4 的倍数；圆角：控件 8–10，卡片 14–20，胶囊 99。阴影只用于记一笔卡和弹层。
触控目标 ≥44px；手机底部操作区留安全区。

## 组件清单
AppShell（侧栏/底栏）、BookSwitcher、Greeting、CaptureCard（说一句 + 手动并排；手机为两个入口）、EntryForm（统一表单：类型切换、金额、摘要、分类网格、钱包/时间/账本行、AA 行、"更多"展开）、FilledBadge（小熊填）、DraftCard（待确认，含缺信息态）、TimelineGroup / TimelineRow、MonthCard、StatPair、ReminderList、Money、Chip、Segmented、ListRow、Sheet、Dialog、Toast、EmptyState（带小熊）。

## 交互规则
- 一句话输入回车即解析；解析中显示进度，完成后字段高亮 1 秒；用户改过的字段不再被后续解析覆盖。
- 识图多张时逐张生成草稿卡；缺日期/期数/手续费等必填项的卡用 attention 态，不能直接记入。
- 保存后提供"撤销"Toast（5 秒）；"保存并再记"保留账本、钱包、日期。
- 删除、权限、家庭成员、余额更正等高风险操作一律二次确认（与阶段 1 助手风险分级一致）。
