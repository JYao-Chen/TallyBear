# 收支分析页面

更新于 2026-10-04。模式为 Operate，面向个人及家庭成员核对费用和钱包实际变化。本文记录当前实现，视觉仍沿用根目录 PRODUCT.md 与 DESIGN.md。

## 页面结构

入口为工作台「收支分析」。页面依次显示三个统计口径、当前口径说明、账本或钱包归属选择、智能核对入口和统计周期。费用视图接着显示收入、当期净支出与收支结余，再显示图表和收支明细。钱包视图接入 WalletFundsPanel，显示资金指标、余额关系、图表和资金明细。

三个口径始终在顶部并列。选中项使用现有面板背景和强调色，桌面附勾选图标；每项保留图标、名称和简短说明。继续使用奶油白页面、暖色文字、圆角面板，以及绿色收入和红色支出。金额使用等宽数字。页面没有新增一套全局设计 token。

## 三个统计口径

| 口径 | 范围与默认选择 | 账务含义 |
| --- | --- | --- |
| 账本收支 / Book expenses | 初始选择当前账本；可选择一个或多个有查看权限的账本 | 按记录归属统计日常消费及当期分摊，同一事件的关联副本只计一次 |
| 我的费用 / My expenses | 切换后默认选择全部可访问账本，也可缩小账本范围 | 日常记录按本人钱包归属；无钱包记录按本人创建者归属；当期分摊按本人承担份额，付款人可以不同于承担人 |
| 钱包资金流 / Wallet cash flow | 默认「我的个人钱包」；可切换家庭共同钱包，再选择全部钱包或单个钱包 | 统计实际付款、收入、退款及已确认家庭往来，分摊不再次扣钱包余额 |

切换口径会清除旧费用汇总；新结果返回前金额显示「—」。账本选择弹层提供「全部可访问账本」及逐项选择，至少保留一个账本。单账本且有写权限才显示批量整理；跨账本与本人费用明细显示账本来源。

## 周期、筛选与导出

共用 ReportPeriodPicker 支持年、月、周、指定日和自定义日期。起止日均包含在内，周范围为周一至周日。自定义范围先编辑再应用；无效范围显示提示并禁用应用按钮。

费用视图提供收支类型、分类、排序和文本搜索，不显示资金账户筛选及转账类型。搜索在短暂等待后提交，筛选变化回到第一页。相同查询用于顶部汇总、每日净支出、费用分类、每日收入、明细和 CSV 导出；汇总覆盖全部匹配记录，明细分页不缩小汇总范围。每日收入图只在收入非零时出现；分类结果含负数时使用柱状图。图表保留金额列表，费用图表下钻携带当前账本、口径、周期和筛选。

导出包含全部匹配结果，沿用当前排序。加载中、搜索尚未提交、无匹配记录或正在导出时禁用导出按钮，失败显示错误。

钱包的搜索、流水方向／类型和排序只作用于下方资金明细。点击「资金流入」「资金流出」「资金净变化」指标也只改变明细方向。周期资金总额、每日资金图和期初／期末余额保持不变。钱包归属、具体钱包和日期则改变整个周期报表；不能把搜索后的明细小计当作期末余额。

## 金额关系

费用净支出 = 消费与当期分摊 − 退款；收支结余 = 收入 − 净支出。转账不计消费，跨账本副本通过事件归属去重。原付款变化导致分摊失效时显示原付款，并出现「部分分摊需要重新核对」提示及计划与分摊入口；这部分结果不能当作完整分摊结果。

钱包资金流入 = 收入 + 退款 + 转入；资金流出 = 消费支付 + 转出；资金净变化 = 流入 − 流出。期末账面余额 = 期初账面余额 + 资金净变化 + 余额校准。期初包含周期开始前的已有流水。

选中范围内的钱包互转在合计中抵消，明细仍显示转账金额并标注「合计不变」。选择单个钱包后，该钱包的转入或转出计入其变化。余额校准单独展示，不作为真实收支。信用账户消费体现负债变化，不能解释为已经支付现金。家庭资金流水只使用已确认往来，不展示其他成员私人钱包余额。资金详情是既有流水的查看入口，不生成新消费或再次扣款。

## 组件与状态

SpendingAnalysis 组织口径、账本选择、周期、费用汇总及图表；RecordsPanel 请求同一费用报表并负责筛选、分页、选择记录和导出；WalletFundsPanel 负责钱包归属内的周期报表及独立明细筛选。Chart、FormSelect、Sheet 和明细排序复用现有组件。

加载状态有文字提示；费用汇总使用 aria-busy，口径按钮使用 aria-pressed。请求失败显示可读错误，费用数据清空；无匹配结果提示调整日期或筛选。资金明细无结果时显示空状态，分页按钮按可用页启用或禁用。资金详情弹层显示类型、日期、来源钱包、转入钱包、交易对方、净余额变化、编号和备注，缺失字段不补造。

## 手机布局

600px 以下，三个口径仍并列，图标置于名称上方，隐藏勾选图标并缩小辅助说明。账本选择和核对入口允许换行；费用三个汇总继续横排，缩小金额字号与内边距。钱包三个资金指标改为纵向整行，标签和金额左右排列；搜索与类型筛选纵排，资金图表单列。余额项允许换行，长标题和详情内容可折行。详情复用手机底部面板，页面继续使用工作台底部导航。
